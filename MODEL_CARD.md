# MediAI 2.0 — Model Card

## Purpose

MediAI 2.0 provides a **preliminary, educational symptom-pattern assessment**. It is not a medical diagnostic device and must not replace a licensed clinician, emergency service, laboratory testing, or imaging.

## Data

The project uses the repository's `dataset/disease_sympts_prec_full.csv` as a benchmark dataset. Each record contains a disease label, a comma-separated symptom list, and optional precaution text. The dataset is treated as an educational benchmark rather than a clinically representative patient cohort.

## Feature representation

The 2.0 pipeline converts symptom lists into a binary symptom-presence matrix. This is more interpretable than relying only on free-text TF-IDF features and allows feature-level analysis.

## Evaluation

The training pipeline compares Logistic Regression, Random Forest, calibrated Linear SVM, and HistGradientBoosting. Evaluation uses StratifiedGroupKFold so repeated records with the same disease and normalized symptom signature are kept together, reducing duplicate leakage between training and test data.

Reported metrics include accuracy, macro precision, macro recall, macro F1, and weighted F1. Results are generated by `ml/train.py` and saved under `results/`.

## Probability and uncertainty

The UI should refer to the returned value as **model probability**, not clinical certainty. A high model probability does not establish that a patient has a disease. Future releases should add a formal probability-calibration study before presenting calibrated uncertainty as a validated confidence measure.

## Safety

`Safety / Triage` is evaluated before routine AI guidance. Selected emergency warning symptoms and clearly abnormal vital readings can escalate the assessment to Emergency or Urgent status. This layer is a safety heuristic, not a clinically validated triage protocol.

## Limitations

- Benchmark data may contain repeated or synthetic-style symptom combinations.
- Symptoms overlap across many conditions.
- The model has no direct access to physical examination, laboratory tests, imaging, medication lists, or complete clinical history.
- Dataset performance does not establish clinical effectiveness.
- Demographic and geographic generalization has not been established.

## Responsible-use rule

Never use a MediAI prediction as the sole basis for treatment, medication changes, or emergency decisions. When symptoms are severe, rapidly worsening, or concerning, seek professional medical care regardless of the model output.
